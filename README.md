# Resounding Modern Warfare Cubed

**Modern Warfare Cubed** is a fork of the popular [Vic's Modern Warfare Mod](https://www.curseforge.com/minecraft/mc-mods/vics-modern-warfare-mod) which is now discontinued aiming to improve and expand upon the experience.

Resounding Modern Warfare Cubed takes that further, and goes well into gun nut territory. I have researched each new addition extensively, and gone back over a lot of the old content to bring it up to the new standard.

The plan for this fork also includes a lot of mapmaker's and server features, in the hope that those who want to make PvE or PvP experiences can make whatever they want, with the mod offering the tools and variety they need to fit any scenario.
## Weapon Customization & Statistics!

Each weapon is *extremely* customizable, this is a firearms playground for you to run wild in: Things can be as practical or as goofy as you want, go wild. 

Every gun has durability, but unlike basic tools, when it breaks it will stop working rather than disappear. Your attachments can then be taken off and put onto a new gun, instead of vanishing into thin air.
## Current Status

This fork is heavily in development, not because of game-breaking bugs, but because there's a whole lot to add and my attention is spread across planning and implementing *all of it*.

Certain guns may have visual glitches, which are targets to go back and polish. Most if not all new content is uncraftable, simply because everything would have to be rebalanced with each addition.
